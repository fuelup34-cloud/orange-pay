# Strawberry Pay

A marketing site and demo app for the fictional "Strawberry Pay", built with React + Vite (JavaScript).

## Run it

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Structure

- `src/index.css` – design tokens (colors, system font stack, type scale), buttons, scroll-reveal
- `src/App.jsx` – page composition
- `src/components/` – Nav, Hero, PhoneMockup, Benefits, Stats, Security, HowItWorks, AcceptPayments, FAQ, GetStarted, Footer
